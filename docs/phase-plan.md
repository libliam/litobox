## 第四阶段：颜色工具 (ColorTool)

### 功能清单

| 功能 | 说明 |
|------|------|
| 颜色选择器 | 拾色器面板，支持 HEX/RGB/HSL 格式 |
| 色板生成 | 互补色、三角色、四角色、类似色 |
| 对比度检查 | WCAG 2.1 AA/AAA 标准对比度检测 |
| CSS 渐变生成 | 线性/径向渐变可视化生成 |
| 颜色转换 | HEX ↔ RGB ↔ HSL ↔ CMYK 互转 |

### 技术实现
- 纯前端实现，无需新依赖
- 可使用 `colord` 库（轻量颜色处理库，可选）

### 页面结构
```
┌─────────────────────────────────────┐
│  Tab栏：选择器 | 转换 | 色板 | 对比度 │
├─────────────────────────────────────┤
│  各Tab独立输入/输出区域              │
└─────────────────────────────────────┘
```

## 第七阶段：二维码工具 (QrTool)

### 功能清单

| 功能 | 说明 |
|------|------|
| 二维码生成 | 文本/URL → 二维码图片 |
| 二维码解码 | 上传图片或从剪贴板粘贴，解析二维码内容 |
| 样式配置 | 尺寸、边距、前景色/背景色 |
| 导出 | 下载为 PNG 图片 |

### 技术实现
- 使用 `qrcode` 库生成（离线可用）
- 使用 `jsqr` 库解码（纯 JS 实现，离线可用）
- 纯前端实现

### 页面结构
```
┌─────────────────────────────────────┐
│  Tab栏：生成 | 解码                  │
├─────────────────────────────────────┤
│  生成Tab：输入文本 → 二维码预览 + 导出│
│  解码Tab：上传图片/粘贴 → 解析结果    │
└─────────────────────────────────────┘
```

## 第八阶段：HTTP 请求测试 (HttpTool)

### 功能清单

| 功能 | 说明 |
|------|------|
| 请求方法 | GET/POST/PUT/DELETE/PATCH |
| URL 输入 | 支持完整 URL + 查询参数 |
| 请求头编辑 | Key-Value 表格编辑 |
| 请求体编辑 | Raw JSON / Form / x-www-form-urlencoded |
| 响应展示 | 状态码、响应头、格式化 Body |
| 历史记录 | 保存最近请求 |

### 技术实现
- 通过 Tauri 后端发起请求（绕过浏览器 CORS 限制）
- 使用 `tauri::http` 或 `reqwest` 库
- 响应格式化使用已有 `jsonUtils` 处理 JSON 响应

### 页面结构
```
┌─────────────────────────────────────┐
│  请求卡片：方法选择 + URL + 发送按钮  │
├─────────────────────────────────────┤
│  请求头卡片：Key-Value 表格          │
├─────────────────────────────────────┤
│  请求体卡片：JSON/Form 编辑          │
├─────────────────────────────────────┤
│  响应卡片：状态码 + 响应头 + Body    │
└─────────────────────────────────────┘
```

## 开发顺序建议

1. **颜色工具** - 前端开发必备，使用频率高
2. **时间戳增强** - 扩展现有功能，开发成本低
3. **密码生成器** - 轻量实用，快速完成
4. **二维码工具** - 实用性强，离线可用
5. **正则增强** - 扩展现有功能，模板库价值高
6. **代码片段** - 本地存储，开发者常用
7. **HTTP 请求** - 需要 Tauri 后端支持，复杂度较高

每个阶段预计 1-3 个文件新增，遵循项目现有模板和规范。
