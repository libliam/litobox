## Bug修复记录

| Bug | 修复方式 |
|-----|----------|
| `toSnakeCase` 产生双下划线（如 `Hello World` → `hello__world`） | 添加 `.replace(/_+/g, '_')` 合并连续下划线 |
| `toTitleCase` 使用废弃API `substr` | 替换为 `slice` |
| `toSnakeCase` 正则替换在PowerShell中 `$1` 被转义 | 使用函数式替换 `(_, char) => '_' + char` |
