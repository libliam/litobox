# LitoBox\-PRD\&TECH文档

# PRD\.md 产品需求文档

## 1\. 产品概述

### 1\.1 产品背景

开发者日常工作中频繁使用JSON格式化、字符串处理、文本编解码等零散工具，网页工具存在广告、网络依赖、隐私泄露风险，本地零散脚本使用繁琐。为提升开发效率，基于Tauri开发一款**轻量化、无网络、无广告、常驻本地**的Windows桌面集成工具箱，统一收纳高频开发小工具。

### 1\.2 运行环境

- 支持系统：Windows 10 1903及以上、Windows 11 全版本

- 运行模式：本地离线运行，无需联网，所有数据本地存储

- 设备适配：支持高分屏、自适应缩放，适配Win10/11系统明暗主题

### 1\.3 产品目标

- 轻量化：安装包体积≤20MB，秒级启动，低内存占用

- 集成化：核心文本、JSON工具一站式集成，多标签并行使用

- 高效化：支持剪贴板快捷操作、全局热键、一键复制结果

- 稳定化：离线运行，无广告、无后台推送，数据本地安全留存

## 2\. 核心功能需求

### 2\.1 全局基础能力（通用）

- **多标签页**：每个工具独立标签，支持新增、关闭标签，互不干扰

- **系统主题适配**：自动跟随Windows深色/浅色模式，支持手动切换

- **窗口能力**：支持窗口置顶、最小化、关闭、缩放自适应

- **托盘常驻**：最小化后隐藏至系统托盘，支持双击托盘图标唤起窗口、右键退出

- **全局热键**：自定义快捷键唤起软件，快速激活工具窗口

### 2\.2 JSON工具箱（核心功能1）

面向开发调试场景，支持不规范JSON兼容处理，实时校验格式化

- **JSON格式化**：支持压缩JSON、单行JSON一键美化缩进，自定义缩进空格（2/4格）

- **JSON压缩**：格式化后的JSON一键压缩为单行紧凑格式

- **语法校验**：实时检测JSON语法错误，标红提示错误位置、错误原因

- **兼容解析**：支持带注释、尾逗号的非标准JSON解析格式化

- **快捷操作**：一键清空输入、一键复制结果、剪贴板粘贴输入

### 2\.3 字符串工具箱（核心功能2）

覆盖开发者高频文本处理场景，支持批量、精细化字符串操作

- **空格处理**：首尾去空格、全局全部去空格、保留换行去空格

- **文本拼接/分割**：多行文本按自定义分隔符（逗号、换行、自定义字符）拼接；指定字符分割文本

- **大小写转换**：全大写、全小写、首字母大写、驼峰/下划线互转

- **文本清理**：去除换行符、去除制表符、批量空行删除

- **快捷操作**：一键撤销、一键复制结果、批量处理

### 2\.4 基础编码工具（拓展功能）

- URL 编码/解码、Base64 编码/解码

- 时间戳与北京时间互转（秒级/毫秒级时间戳）

### 2\.5 本地数据能力

- 工具操作历史本地缓存，关闭软件重启后保留最近10条记录

- 用户主题偏好、热键配置、缩进配置本地持久化

## 3\. 交互需求

- 所有工具支持**实时预览**：输入内容即时生成处理结果，无需手动刷新

- 操作反馈：复制成功、格式错误、空输入等场景给出轻量提示

- 简洁无冗余：无广告、无弹窗、无推荐内容，界面专注工具功能

- 适配键盘操作：支持快捷键粘贴、清空、复制、切换标签

## 4\. 非功能需求

### 4\.1 性能需求

- 软件启动时间≤1s，工具操作响应≤100ms

- 空闲内存占用≤50MB，大文本（10w字符）处理无卡顿

- 打包体积：便携单文件exe≤15MB，安装包≤20MB

### 4\.2 兼容性需求

- 完全兼容Windows10/Windows11全系系统

- 适配1080P、2K、4K高分屏，界面无模糊、错位

### 4\.3 安全需求

- 纯本地离线运行，无网络请求、无数据上传

- 所有用户数据仅保存在本地电脑，无隐私泄露风险

# TECH\.md 技术设计文档

## 1\. 技术栈整体方案

### 1\.1 核心架构

采用 **Tauri 2\.0 \+ Vue3 \+ TypeScript** 前后端一体架构，替代传统Electron，兼顾开发效率、轻量体积和系统原生性能

### 1\.2 技术明细

- **前端框架**：Vue3（Composition API）\+ Vite（极速构建）

- **类型约束**：TypeScript，统一代码规范，减少运行报错

- **UI组件库**：Element Plus（简洁适配桌面端，表单/按钮/标签成熟）

- **桌面内核**：Tauri 2\.0（Rust底层，原生系统调用，无Chromium冗余）

- **核心工具依赖**：
        

    - json5：兼容非标准JSON（带注释、尾逗号）解析

    - prettier：标准化JSON格式化排版

    - lodash：高效字符串、数组批量处理

    - js\-base64：Base64编解码实现

- **本地存储**：localStorage（轻量化存储配置、操作历史）

- **打包工具**：Tauri官方打包工具，支持单文件便携版\+MSI安装包

## 3\. 核心功能技术实现方案

### 3\.1 JSON工具箱实现

1. **解析兼容**：使用json5解析用户输入文本，规避标准JSON不支持注释、尾逗号的问题，提升兼容性

2. **格式化排版**：通过prettier结合json解析器，支持2/4空格缩进，统一格式化风格

3. **语法校验**：捕获解析异常，提取错误信息并定位错误行数，前端标红提示

4. **压缩处理**：解析JSON对象后，通过JSON\.stringify去除缩进、空格，实现极简压缩

5. **剪贴板交互**：调用Tauri原生剪贴板API，实现无授权读写剪贴板，比浏览器API更稳定

### 3\.2 字符串工具箱实现

1. **空格处理**：基于lodash\.trim实现首尾去空，正则全局匹配/\\s/g实现全部去空格，精准区分换行、空格、制表符

2. **文本拼接分割**：支持自定义分隔符，分割后自动去空行、去空白，拼接时兼容多行文本

3. **格式转换**：封装大小写、驼峰、下划线转换工具函数，统一处理规则

4. **实时响应**：监听输入框change事件，实时执行处理逻辑，即时输出结果

### 3\.3 系统桌面能力实现（Tauri原生）

1. **托盘常驻**：在src\-tauri底层开启托盘权限，配置托盘图标、右键菜单（显示窗口、退出程序）

2. **全局热键**：基于Tauri global\-shortcut插件，注册系统级快捷键，支持自定义配置

3. **主题适配**：监听Windows系统主题切换事件，动态切换页面明暗样式，支持手动覆盖配置

4. **窗口控制**：封装窗口置顶、最小化、自适应缩放方法，适配Windows窗口交互逻辑

### 3\.4 本地数据持久化

- 用户配置（主题、缩进格式、默认分隔符）：永久存储，手动重置清空

- 操作历史：存储最近10条操作记录，自动淘汰旧数据，避免缓存冗余

- 所有数据存储在本地用户目录，不联网、不对外传输

## 4\. 权限与安全设计

### 4\.1 权限最小化

修改tauri\.conf\.json，关闭所有无用网络权限、文件读写权限，仅保留：剪贴板读取写入、窗口控制、全局热键、本地存储权限，杜绝安全风险。

### 4\.2 安全隔离

- 前端业务逻辑与原生系统能力隔离，所有系统调用通过Tauri官方API，无原生漏洞风险

- 禁止所有网络请求，彻底杜绝数据上传、广告加载、远程注入问题

## 5\. 打包与部署方案

### 5\.1 开发调试命令

- `npm run tauri dev`：本地热更新调试，支持前端、Rust底层实时预览

### 5\.2 生产打包命令

- `npm run tauri build`：一键打包，生成两种产物
        

    1. 便携版：单文件 \.exe，免安装、即开即用

    2. 安装版：\.msi 安装包，支持系统注册、快捷方式创建、标准卸载

### 5\.3 打包优化配置

- 开启代码压缩、依赖树摇，剔除无用代码和依赖

- 关闭调试日志、sourceMap，减小包体积

- 适配Windows高DPI缩放，修复界面模糊问题

- 配置Win10兼容模式，保证低版本系统正常运行

## 6\. 性能优化方案

- **启动优化**：Vite按需引入组件，路由懒加载，减少首屏加载资源

- **渲染优化**：大文本处理采用虚拟滚动，避免DOM渲染卡顿

- **内存优化**：页面销毁清空监听事件、缓存数据，避免内存泄漏

- **运算优化**：工具函数纯函数封装，缓存重复运算结果，提升响应速度
