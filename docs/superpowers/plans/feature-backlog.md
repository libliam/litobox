## 候选方向池（待规划）

> 从各次 brainstorming 中收集的潜在功能，按大类分组，优先级从高到低排列。
> 每次选定一个方向做细化设计时，从这里移到 "规划中" 区域。

### A. 系统工具增强（Rust 后端驱动）

基于现有系统工具页，增加可操作能力。

| # | 方向 | 说明 | 优先级 | 来源 |
|---|------|------|--------|------|
| A1 | ✅ 进程 kill + 端口释放 | ProcessListView 加结束按钮、NetworkInfoView 加释放按钮 | — 已完成 V4.4 — | 2026-07-06 brainstorming |
| A2 | **Windows 服务管理** | 查看系统服务列表，支持启动/停止/重启，按状态筛选 | 高 | 2026-07-06 brainstorming |
| A3 | **计划任务管理** | 查看 Windows 计划任务列表，支持启用/禁用/删除 | 中 | 2026-07-06 brainstorming |
| A4 | **开机启动项管理** | 在软件环境的开机启动项基础上，支持新增/删除/启用/禁用 | 中 | 2026-07-06 brainstorming |
| A5 | **注册表查看器** | 只读浏览注册表（只读模式，安全），支持搜索 key/value | 低 | 系统工具扩展 |
| A6 | **环境变量编辑** | 在软件环境的 env var 基础上，支持新增/修改/删除用户级环境变量 | 中 | 系统工具扩展 |
| A7 | **进程树视图** | 进程列表按父子关系树形展示，支持展开/折叠 | 低 | 进程列表增强 |

## 维护规则

1. **每次 brainstorming 后立即更新此文件** — 把新产生的方向追加到对应分类，标注日期和来源
2. **开始实现时移动到"规划中"** — 创建 spec/plan 后从候选池移除
3. **版本发布时移动到"已完成版本"** — 标注完成日期和版本号
4. **放弃的方向标注"已放弃"并说明原因** — 不删除，保留决策记录
5. **优先级参考标准**：
   - **高**：开发常用 / 痛点明确 / 实现成本低 / 复用现有代码多
   - **中**：实用但非高频 / 有一定实现难度
   - **低**：锦上添花 / 实现成本高 / 使用频率低
