## 第二阶段：第二优先级（实用 + 中等复杂度）

### 5. CSS工具 (CssTool.vue)

**功能**:
- 颜色格式转换：Hex ↔ RGB ↔ HSL 互相转换
- 单位换算：px ↔ rem ↔ em ↔ vw/vh
- CSS 压缩/格式化
- 颜色选择器（可视化选取颜色）

**技术实现**:
- 纯前端颜色计算
- 正则表达式解析 CSS 属性

**页面结构**:
- 操作卡片：功能切换（颜色转换/单位换算/CSS压缩）
- 输入卡片：CSS 代码或颜色值输入
- 输出卡片：转换结果展示

### 6. JWT解析 (JwtTool.vue)

**功能**:
- 解析 JWT token 三段结构
- 展示 Header（算法、类型）
- 展示 Payload（用户信息、过期时间）
- 验证签名（可选，需输入密钥）
- 高亮过期字段

**技术实现**:
- Base64 解码（已有 encodeUtils）
- JSON 解析
- 时间戳格式化

**页面结构**:
- 操作卡片：解析按钮、签名验证（可选密钥输入）
- 输入卡片：JWT token 输入
- 输出卡片：Header/Payload 分段展示（JSON 格式化）

### 7. 字数统计 (WordCountTool.vue)

**功能**:
- 字符数（含/不含空格）
- 单词数（英文）/ 字数（中文）
- 行数、段落数
- 阅读时间估算（中文/英文不同速度）
- 词频统计（Top N 高频词）

**技术实现**:
- 正则表达式分词
- 简单的词频统计算法

**页面结构**:
- 操作卡片：统计按钮、词频 Top N 设置
- 输入卡片：文本输入
- 输出卡片：统计数据卡片 + 词频表格

### 8. Cron表达式生成 (CronTool.vue)

**功能**:

- 常用表达式模板（每分钟、每小时、每天等）

- 表达式校验

**技术实现**:
- 纯前端 Cron 表达式构建
- 日期计算（下次执行时间）

**页面结构**:
- 操作卡片：常用模板选择、生成按钮
- 配置卡片：6 个时间维度的可视化选择器
- 输出卡片：Cron 表达式 + 下次执行时间

## 实施建议

1. **按优先级顺序**：先做第二优先级的 3 个工具（CSS/JWT/字数统计），验证后再做第三优先级
2. **渐进式开发**：每次实现 1-2 个工具，保持迭代节奏
3. **质量保障**：每个新功能都遵循现有的代码规范和 UI 设计规范
4. **复用已有代码**：尽量复用 encodeUtils、jsonUtils 等已有工具函数

## 备注

- 所有新功能继续遵循"纯本地离线运行"原则
- 保持轻量化设计，避免引入不必要的依赖
- 新功能页面继续遵循科技风 UI 规范（卡片式布局、CSS 变量、统一操作/输入/输出结构）
