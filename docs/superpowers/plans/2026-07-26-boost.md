# 一键加速 Implementation Plan

**Goal:** 新增一键加速工具，支持内存释放（EmptyWorkingSet）+ 临时文件清理 + 回收站清空。

**Architecture:** 新增 `boost.rs` 后端模块（Rust 原生内存释放 + 临时文件清理 + PowerShell 回收站清空），新增 `BoostView.vue` 前端页面（扫描卡片 + 一键执行 + 结果展示）。

**Tech Stack:** Rust (windows-sys EmptyWorkingSet, std::fs), PowerShell (Clear-RecycleBin), Vue 3 + Element Plus + TypeScript

---

### Task 1: 创建后端 boost.rs 模块

**Files:**
- Create: `src-tauri/src/boost.rs`

- [ ] **Step 1: 添加 windows-sys features**

在 `Cargo.toml` 的 `windows-sys` features 中添加 `Win32_System_ProcessStatus`（如果还没有的话），用于 `EmptyWorkingSet`。

- [ ] **Step 2: 创建 boost.rs**

实现三个函数：
- `boost_scan()` - 扫描内存/临时文件/回收站
- `boost_execute()` - 执行三项清理
- 内存释放用 Rust 原生 `windows-sys` 调用 `EmptyWorkingSet`
- 临时文件清理用 Rust `std::fs` 遍历删除
- 回收站清空用 PowerShell `Clear-RecycleBin -Force`
