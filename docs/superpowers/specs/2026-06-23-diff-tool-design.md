# 文本代码对比工具 - 设计文档

## 概述

新增文本/代码对比工具，支持左右双栏输入，高亮展示差异，提供行级和字符级两种对比模式。

## 功能需求

### 核心功能
- 左右双栏文本输入
- 行级对比：以行为单位，标记新增/删除/修改行
- 字符级对比：在同一行内高亮具体变化的字符
- 双栏同步滚动
- 自动执行对比（输入变化后自动触发）

### 设置选项
- 对比模式切换（行级/字符级）
- 自动执行开关
- 忽略空白字符开关
- 忽略大小写开关

## 技术方案

### 依赖
- `diff` npm 包：提供行级和字符级 diff 算法

### 文件结构
```
src/
├── views/
│   ── DiffTool.vue          # 主页面组件
├── utils/
│   └── diffUtils.ts          # diff 算法封装
```

### 数据流
```
用户输入 → 防抖(300ms) → diffUtils → 差异数据 → 渲染双栏视图
```

### 差异高亮规则
| 类型 | 左栏 | 右栏 |
|------|------|------|
| 相同 | 正常 | 正常 |
| 删除 | 红色背景 | - |
| 新增 | - | 绿色背景 |
| 修改 | 橙色背景+字符高亮 | 橙色背景+字符高亮 |

## UI 布局

```
[操作区 - 置顶]
  对比模式 | 自动执行 | 设置面板

[左栏输入]          [右栏输入]
textarea            textarea
[清空][粘贴]        [清空][粘贴]

[对比结果 - 双栏]
左栏（原始）  |  右栏（修改后）
行号|内容     |  行号|内容
```

1. 安装 `diff` 依赖
2. 创建 `diffUtils.ts` 工具函数
3. 创建 `DiffTool.vue` 页面组件
4. 注册路由和侧边栏入口
5. 测试验证
