**日期**: 2026-06-18

## 概述

V1.2 进阶版本包含4个新功能：
1. 窗口置顶快捷按钮
2. 自定义快捷键
3. 批量文本处理
4. 文件编码转换

按实现优先级排序：窗口置顶 → 自定义快捷键 → 批量文本处理 → 文件编码转换

## 一、窗口置顶快捷按钮

### 功能描述
在侧边栏添加置顶按钮，点击后应用窗口始终保持在最顶层。

### 技术方案
- 使用 Tauri 2.0 的 `@tauri-apps/api` 中的 `getCurrentWindow().setAlwaysOnTop()` 方法
- 前端使用 Vue ref 管理置顶状态
- UI 使用 📌 图标按钮，置顶时高亮显示

### 影响文件
- `src/components/SidebarNav.vue` - 添加置顶按钮
- 无需修改 Rust 端代码（Tauri 2.0 内置支持）

### UI 设计
- 位置：侧边栏底部，主题选择器旁边
- 样式：圆形按钮，默认灰色，置顶时变为青色高亮
- 交互：点击切换状态，显示 tooltip 提示

## 二、自定义快捷键

### 功能描述
允许用户自定义全局快捷键，快速切换到指定工具页面。

### 技术方案
- 前端：在 Pinia store 中添加 `shortcuts` 配置项
- Rust 端：使用 `tauri-plugin-global-shortcut` 注册全局热键
- 快捷键格式：`Ctrl+Alt+X` 组合键
- 提供快捷键录制功能（用户按键自动捕获）

### 快捷键配置
```typescript
interface ShortcutsConfig {
  json: string      // 默认: Ctrl+Alt+J
  string: string    // 默认: Ctrl+Alt+S
  encode: string    // 默认: Ctrl+Alt+E
  regex: string     // 默认: Ctrl+Alt+R
  base: string      // 默认: Ctrl+Alt+B
  uuid: string      // 默认: Ctrl+Alt+U
  batch: string     // 默认: Ctrl+Alt+T
  fileEncoding: string  // 默认: Ctrl+Alt+F
}
```

### 影响文件
- `src/store/index.ts` - 添加 shortcuts 配置
- `src-tauri/Cargo.toml` - 添加 `tauri-plugin-global-shortcut`
- `src-tauri/src/main.rs` - 注册全局热键
- `src/App.vue` - 监听热键事件切换工具
- `src/components/SidebarNav.vue` - 添加快捷键配置入口

### 实现细节
1. 应用启动时从 store 读取快捷键配置
2. Rust 端通过 `global_shortcut` 插件注册热键
3. 热键触发时发送事件到前端
4. 前端监听事件并切换工具页面
5. 提供配置面板让用户修改快捷键

## 三、批量文本处理

### 功能描述
支持同时处理多个文本片段，统一应用字符串操作。

### 技术方案
- 新增 `BatchTextTool.vue` 页面
- 复用 `stringUtils.ts` 的处理函数
- 支持多行输入，每行作为独立文本片段
- 批量处理后显示结果列表
