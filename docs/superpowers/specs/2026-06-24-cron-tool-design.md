# Cron表达式生成器设计文档

**日期**: 2026-06-24
**状态**: 设计中

## 概述

在 LitoBox 工具箱中新增 Cron 表达式生成器（CronTool.vue），提供可视化界面帮助用户生成和校验 Cron 表达式，支持 5 字段和 6 字段两种格式。

## 功能需求

### 核心功能

1. **可视化格子面板** — 每个时间维度（秒/分/时/日/月/周）提供格子面板，点击格子选中/取消
2. **双格式支持** — 5 字段（分时日月周）和 6 字段（秒分时日月周）可切换
3. **常用模板** — 10 个预设模板一键填充
4. **表达式预览** — 实时显示生成的 Cron 表达式，带字段标注
5. **下次执行时间** — 计算并显示下一次触发时间
6. **表达式校验** — 验证表达式合法性并给出错误提示
7. **双向绑定** — 可视化操作 ↔ 手动输入框 ↔ 表达式预览，三者同步

### 常用模板（10个）

| 序号 | 模板名称 | 5字段表达式 | 6字段表达式 |
|------|---------|------------|------------|
| 1 | 每分钟 | `* * * * *` | `* * * * * *` |
| 2 | 每5分钟 | `*/5 * * * *` | `0 */5 * * * *` |
| 3 | 每小时 | `0 * * * *` | `0 0 * * * *` |
| 4 | 每2小时 | `0 */2 * * *` | `0 0 */2 * * *` |
| 5 | 每天零点 | `0 0 * * *` | `0 0 0 * * *` |
| 6 | 工作日每天9点 | `0 9 * * 1-5` | `0 0 9 * * 1-5` |
| 7 | 工作日9点和18点 | `0 9,18 * * 1-5` | `0 0 9,18 * * 1-5` |
| 8 | 每周日零点 | `0 0 * * 0` | `0 0 0 * * 0` |
| 9 | 每月1号零点 | `0 0 1 * *` | `0 0 0 1 * *` |
| 10 | 每年1月1日零点 | `0 0 1 1 *` | `0 0 0 1 1 *` |

## 格子面板设计

### 每个维度面板包含

1. **标题栏**：维度名称 + 手动输入框（可直接输入该维度的 cron 值）
2. **快捷按钮行**：`*`（全选）、`清空`、`反选`
3. **格子区域**：
   - **秒**：60 个格子（0-59），每行 12 个，共 5 行
   - **分**：60 个格子（0-59），每行 12 个，共 5 行
   - **时**：24 个格子（0-23），每行 12 个，共 2 行
   - **日**：31 个格子（1-31），每行 10 个，共 4 行
   - **月**：12 个格子（1-12），每行 6 个，共 2 行
   - **周**：7 个格子（0-6，周日到周六），每行 7 个，共 1 行

### 选中状态

- **未选中**：灰色边框，透明背景
- **选中**：青色填充（`var(--accent-cyan)`），发光效果
- **点击**：切换选中/取消状态

### 范围选择

- **Shift + 点击**：选中从上次点击到当前点击的范围
- **拖拽选择**：鼠标按下拖过多个格子批量选中

## 数据流

```
可视化格子点击 → 更新维度选中集合(Set) → 构建Cron表达式 → 更新预览区
     ↑                                              ↓
手动输入框修改 ← 解析Cron表达式 ← 常用模板选择/格式切换
```

## 技术实现

### 状态管理

每个维度维护一个 `Set<number>` 存储选中的值：

```typescript
interface CronState {
  second: Set<number>   // 0-59 (6字段时启用)
  minute: Set<number>   // 0-59
  hour: Set<number>     // 0-23
  day: Set<number>      // 1-31
  month: Set<number>    // 1-12
  weekday: Set<number>  // 0-6 (0=周日)
}
```

### 表达式构建（Set → Cron 字符串）

将 Set 转换为最优 cron 语法：

| 选中值 | 生成表达式 |
|--------|-----------|
| 全选（0-59） | `*` |
| 连续范围（1,2,3,4,5） | `1-5` |
| 等差序列（0,5,10,15...） | `*/5` |
| 离散值（1,3,5,7） | `1,3,5,7` |

### 表达式解析（Cron 字符串 → Set）

| 表达式 | 解析结果 |
|--------|---------|
| `*` | 全选 |
| `1-5` | 1,2,3,4,5 |
| `*/5` | 0,5,10,15... |
| `1,3,5` | 1,3,5 |
| `1-5/2` | 1,3,5 |

### 下次执行时间计算

- 从当前时间开始，逐分钟模拟匹配
- 找到下一个匹配的时间点
- 最多查找 1 年内的执行时间
- 纯前端计算，不依赖外部库

### 表达式校验

- 检查每个字段是否在合法范围内
- 检查语法是否正确（数字、范围、步长、逗号组合）
- 显示校验结果（有效/错误信息）
