> 日期：2026-06-23

## 功能概览

V2.2 新增两个独立工具：
1. **剪贴板历史** — Rust 后端轮询系统剪贴板，前端 localStorage 存储，支持监听开关、搜索、一键清空
2. **图片工具** — 纯前端 Canvas 处理，支持压缩、缩放、转 Base64

### 1.2 Rust 后端

**文件：`src-tauri/src/clipboard.rs`**

**依赖：**
```toml
# Cargo.toml
arboard = "3.3"
```

**Tauri 命令：**
```rust
#[tauri::command]
async fn start_clipboard_monitor(app: tauri::AppHandle)

#[tauri::command]
async fn stop_clipboard_monitor()

#[tauri::command]
async fn is_monitoring() -> bool

#[tauri::command]
async fn copy_to_clipboard(text: String) -> Result<(), String>
```

**内部状态：**
```rust
static MONITORING: AtomicBool = AtomicBool::new(true);
static LAST_CLIPBOARD: Mutex<String> = Mutex::new(String::new());
```

**轮询逻辑：**
- 启动后台线程，每 500ms 读取一次系统剪贴板
- 对比上次内容，有变化则通过 `app.emit()` 发送事件
- 忽略空内容和与上次相同的内容
- `MONITORING` 为 false 时线程休眠（不退出，等待重新开启）

### 1.4 数据存储

**localStorage key：** `clipboard_history`

**数据结构：**
```typescript
interface ClipboardRecord {
  text: string;
  timestamp: number;  // Date.now()
}
```

**限制策略：**
```typescript
const MAX_RECORDS = 1000;
const MAX_STORAGE_SIZE = 3 * 1024 * 1024;     // 3MB
const SAFE_STORAGE_SIZE = 2.5 * 1024 * 1024;  // 2.5MB

function addRecord(text: string) {
  const records = getRecords();
  records.unshift({ text, timestamp: Date.now() });

  // 按条数裁剪
  while (records.length > MAX_RECORDS) {
    records.pop();
  }

  // 按大小裁剪
  while (estimateSize(records) > MAX_STORAGE_SIZE) {
    records.pop();
  }

  localStorage.setItem('clipboard_history', JSON.stringify(records));
}
```

**大小估算：** `JSON.stringify(records).length * 2`（UTF-16 字节）

|--------|------|------|------|
| `clipboard://new-entry` | Rust → 前端 | `{ text: string }` | 检测到新剪贴板内容 |

### 2.3 技术实现

**图片压缩：**
```typescript
function compressImage(file: File, quality: number): Promise<Blob> {
  return new Promise((resolve) => {
    const img = new Image();
    img.onload = () => {
      const canvas = document.createElement('canvas');
      canvas.width = img.width;
      canvas.height = img.height;
      const ctx = canvas.getContext('2d')!;
      ctx.drawImage(img, 0, 0);
      canvas.toBlob(
        (blob) => resolve(blob!),
        'image/jpeg',
        quality / 100
      );
    };
    img.src = URL.createObjectURL(file);
  });
}
```

**尺寸缩放：**
```typescript
function resizeImage(file: File, width: number, height: number): Promise<Blob> {
  return new Promise((resolve) => {
    const img = new Image();
    img.onload = () => {
      const canvas = document.createElement('canvas');
      canvas.width = width;
      canvas.height = height;
      const ctx = canvas.getContext('2d')!;
      ctx.drawImage(img, 0, 0, width, height);
      canvas.toBlob((blob) => resolve(blob!), 'image/png');
    };
    img.src = URL.createObjectURL(file);
  });
}
```

**图片转 Base64：**
```typescript
function imageToBase64(file: File): Promise<string> {
  return new Promise((resolve) => {
    const reader = new FileReader();
    reader.onload = () => resolve(reader.result as string);
    reader.readAsDataURL(file);
  });
}
```

## 5. 错误处理

### 剪贴板
- 剪贴板读取失败（如其他应用独占）：静默跳过，不弹窗
- localStorage 写入失败（超限）：自动裁剪后重试，仍失败则提示用户
- 复制失败：提示「复制失败，请手动选择」

### 图片工具
- 不支持的图片格式：提示「仅支持 PNG/JPG/WebP/BMP 格式」
- Canvas 处理失败：提示「图片处理失败，请重试」
- 超大图片（>50MB）：提示「图片过大，建议小于 20MB」
