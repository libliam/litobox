# LitoBox - 设计文档

## 概述

基于Tauri 2.0 + Vue3 + TypeScript + Element Plus构建的Windows桌面开发工具箱，提供JSON处理、字符串处理、基础编码等高频开发工具。纯本地离线运行，无网络请求。

## 架构设计

### 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                    Tauri 2.0 壳层                        │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────┐  │
│  │   托盘管理   │  │  全局热键   │  │   窗口控制      │  │
│  └─────────────┘  └─────────────┘  └─────────────────┘  │
├─────────────────────────────────────────────────────────┤
│                   WebView (Vue3)                         │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────┐  │
│  │  JSON工具箱  │  │ 字符串工具箱│  │   编码工具箱    │  │
│  └─────────────┘  └─────────────┘  └─────────────────┘  │
│  ┌─────────────────────────────────────────────────────┐ │
│  │              公共组件层 (Element Plus)               │ │
│  └─────────────────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────────────────┐ │
│  │              工具函数层 (纯函数)                     │ │
│  └─────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────┤
│                   本地存储 (localStorage)                │
└─────────────────────────────────────────────────────────┘
```

### 数据流

1. 用户输入 → 实时监听 → 工具函数处理 → 结果展示
2. 配置变更 → Pinia状态更新 → localStorage持久化
3. 操作完成 → 历史记录更新 → 最多保留10条

## 核心模块设计

### 1. JSON工具箱

**功能**:
- JSON格式化（支持2/4空格缩进）
- JSON压缩（单行紧凑格式）
- 语法校验（实时错误提示）
- 兼容解析（json5支持注释、尾逗号）

**实现**:
- 使用json5.parse()解析非标准JSON
- 使用JSON.stringify()进行压缩
- 捕获解析异常，提取错误信息
- 实时监听输入框变化

**组件结构**:
```
JsonTool.vue
├── ToolInput.vue (输入区)
├── ToolOutput.vue (输出区)
├── ToolActions.vue (操作按钮)
└── jsonUtils.ts (工具函数)
```

### 2. 字符串工具箱

**功能**:
- 空格处理（首尾去空/全局去空/保留换行去空）
- 文本拼接/分割（自定义分隔符）
- 大小写转换（大写/小写/首字母大写/驼峰/下划线）
- 文本清理（去除换行/制表符/空行）

**实现**:
- 正则表达式处理空格和特殊字符
- lodash工具函数辅助处理
- 纯函数封装，支持批量操作

### 3. 编码工具箱

**功能**:
- URL编码/解码
- Base64编码/解码
- 时间戳转换（秒级/毫秒级 ↔ 北京时间）

**实现**:
- encodeURIComponent/decodeURIComponent处理URL
- js-base64库处理Base64
- Date对象处理时间戳转换

### 4. 系统能力

**托盘常驻**:
- Tauri系统托盘API
- 双击托盘图标唤起窗口
- 右键菜单（显示窗口/退出）

**全局热键**:
- Tauri global-shortcut插件
- 默认快捷键：Ctrl+Alt+T
- 支持自定义配置

**主题适配**:
- 监听Windows系统主题变化
- 自动切换Element Plus深色/浅色模式
- 支持手动覆盖配置

**多标签页**:
- Element Plus Tabs组件
- 每个工具独立标签
- 支持新增、关闭标签

## 本地存储设计

### 存储结构

```json
{
  "toolbox_config": {
    "theme": "auto",          // auto/dark/light
    "json_indent": 2,         // 2或4
    "hotkey": "Ctrl+Alt+T",   // 全局热键
    "last_tool": "json"       // 上次使用的工具
  },
  "toolbox_history": [
    {
      "tool": "json",
      "action": "format",
      "timestamp": "2026-06-17T10:30:00Z",
      "input_preview": "{...}",
      "output_preview": "{...}"
    }
  ]
}
```

### 存储规则
- 配置数据永久存储
- 操作历史最多10条，先进先出
- 所有数据本地存储，不上传

## 性能优化

1. **启动优化**: Vite按需加载，路由懒加载
2. **渲染优化**: 大文本使用虚拟滚动
3. **内存优化**: 页面销毁时清理监听器和缓存
4. **运算优化**: 工具函数纯函数设计，缓存重复计算结果

## 安全设计

1. **权限最小化**: 仅保留剪贴板、窗口控制、热键、本地存储权限
2. **网络隔离**: 禁止所有网络请求
3. **数据隔离**: 前端逻辑与原生系统能力通过Tauri官方API交互

## 错误处理

1. **JSON解析错误**: 标红提示错误位置和原因
2. **空输入处理**: 轻量提示用户输入内容
3. **操作反馈**: 复制成功、格式错误等场景给出提示
4. **异常捕获**: 所有工具函数使用try-catch包裹

## 测试策略

1. **单元测试**: 工具函数纯函数测试
2. **组件测试**: Vue组件渲染和交互测试
3. **集成测试**: Tauri原生能力测试（托盘、热键、窗口）
4. **性能测试**: 大文本处理性能验证
